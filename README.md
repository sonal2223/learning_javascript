# 📘 JavaScript Learning Repository

Welcome to my **JavaScript Learning Repository**! 🚀

This repository contains my hands-on practice and learning journey with **JavaScript**, covering fundamental concepts through practical HTML and JavaScript examples. The purpose of this repository is to strengthen my understanding of JavaScript and build a strong foundation for web development.

## 📌 About

This repository includes beginner-friendly examples and practice programs related to core JavaScript concepts such as variables, data types, operators, arrays, DOM manipulation, events, and form validation.

Each example is created to understand how JavaScript works in real web pages and how it can be used to make websites interactive and dynamic.

## ▶️ How to Run

1. Clone this repository to your local system.
2. Open the repository folder in **VS Code** or any preferred editor.
3. Open any `.html` file in a web browser.
4. Open the browser's **Developer Tools → Console** to view JavaScript output.
5. Modify the examples and experiment with the code to practice JavaScript concepts.
